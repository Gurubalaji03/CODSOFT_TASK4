# Task 4 - Quiz Application with Timer

## CodSoft Java Development Internship

### Description
A Java-based quiz application that displays multiple-choice questions, allows users to submit answers within a time limit, calculates the score, and displays the final result.

### Features
- Multiple-choice questions
- One question displayed at a time
- Timer for each question
- Answer validation
- Score calculation
- Correct and wrong answer tracking
- Final result and percentage

### Technologies Used
- Java
- Eclipse IDE

### Java Concepts Used
- Arrays
- 2D Arrays
- Loops
- Conditional Statements
- Exception Handling
- ExecutorService
- Scanner
